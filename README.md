## 🚀 Running on Localhost

or
```bash
node server.js
```
The server will be live at **`http://localhost:3000/`**.

This directory is an initialized Git repository with all clean commits ready.

To push to your GitHub account:
1. Create a new repository on [GitHub](https://github.com/new) named `wedding-invitation-website` (or any name you prefer).
2. Run the following commands in this directory:
```bash
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY_NAME.git
git branch -M main
git push -u origin main
```
